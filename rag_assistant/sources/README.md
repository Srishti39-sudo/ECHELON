# Original source documents

**Put the downloaded PDFs in this folder.**

This is evidence, not corpus. Nothing here is indexed. The documents in `kb/`
are written from these files, and this folder is what makes any quote in an
answer traceable back to a real publication.

For each file, note the URL it came from and the date you retrieved it. Those
become `source_url:` and `retrieved:` in the front matter of the `kb/` document
written from it.

Keep the publisher's filename, or include the publisher and year if you rename:
`gichd-underwater-eo-2025.pdf`.

PDF as downloaded from the publisher is the preferred form. Do not convert to
Word or re-export; every conversion is a chance to lose a table, and the tables
are where the numbers are. For a web page with no PDF version, print to PDF.

A file named `*.NEEDED.txt` is a placeholder for a document that could not be
retrieved automatically. Save the real one, then delete the placeholder.
